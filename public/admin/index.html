➕ Adicionar MikroTik

📋 Como configurar um novo MikroTik

1. No novo MikroTik, libere a API para o servidor: /ip service set api disabled=no port=8728 address=2.24.115.134/32
2. Configure o hotspot (assistente /ip hotspot setup) e o perfil de usuário, e libere o portal no walled garden: /ip hotspot walled-garden add dst-host=wifi.virgemdalapa.mg.gov.br e /ip hotspot walled-garden ip add action=accept dst-host=wifi.virgemdalapa.mg.gov.br
3. Cadastre o roteador aqui em cima e anote o número dele (coluna #).
4. No terminal do MikroTik, baixe a página de login já apontada para ele (troque o N pelo número):
/tool fetch url="https://wifi.virgemdalapa.mg.gov.br/mikrotik-login/N" dst-path=hotspot/login.html
(se der "permission denied", apague antes com /file remove hotspot/login.html — ou crie via /file add)
5. Clique em Testar na lista pra confirmar a conexão. Pronto: os leads desse local já chegam identificados.
